# public/assets/

Veröffentlichte Assets — Bilder, PDFs, Schriften.

Das ist **kein** Ort, an dem Material aus `input/` automatisch landet. Eine Datei
hier erscheint unverändert im öffentlichen Build. Übernahme also nur nach
bewusster Prüfung, und im Commit-Message damit, aus welchem `input/`-Ordner sie
stammt (AGENTS.md R-04).
